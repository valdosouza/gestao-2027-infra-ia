 Consultar pagamentos de CBS
 1. Objetivo
 Retorna as atualizações de pagamentos de CBS que extinguem os débitos do contribuinte, compreendendo: o pagamento do próprio contribuinte e o recolhimento de seus adquirentes.
 Esta API funciona em modo assíncrono. Para orientações de uso, consulte as Regras Comuns às APIs Assíncronas da Apuração de CBS: regras de APIs assíncronas

 3. Regras de retorno
 Para solicitações com consulta concluída nos últimos 3 meses, são retornadas as inclusões e atualizações desde a data de atualização da solicitação concluída mais recente, limitada aos últimos 8 dias. Quando não há consulta concluída nesse período, a busca começa no 1º dia do mês corrente.
 4. Endpoint da api
 URL de Produção: 
 https://api.receitafederal.gov.br/apuracao-cbs/v2/pagamentos/{cnpj}

 Campo 
 Formato 
 Descrição 
 urlRetorno 
 String 
 Opcional. URL do webhook para receber a notificação de retorno. Quando não houver webhook, informar "" (string vazia). 
 4.4 Acionar o endpoint
 Substitua $TOKEN pelo valor de access_token .
 Substitua {cnpj} pelo CNPJ base com 8 dígitos .
 Opcionalmente, informe no corpo uma urlRetorno (URL do webhook) acessível por HTTP ou HTTPS para receber a notificação de conclusão da solicitação ou de erro no processamento. Quando não houver webhook, informar "" (string vazia). Sem esse campo, consulte a situação da solicitação para acompanhar o processamento.
 Exemplo de chamada (com variável TOKEN)
 curl --location --request POST 'https://api.receitafederal.gov.br/apuracao-cbs/v2/pagamentos/{cnpj}' \
 --header "Authorization: Bearer $TOKEN" \
 --header 'Content-Type: application/json' \
 --data '{ "urlRetorno": "https://cliente.exemplo.com/webhooks/apuracao-cbs" }'
 Exemplo com dados fictícios
 curl --location --request POST 'https://api.receitafederal.gov.br/apuracao-cbs/v2/pagamentos/12345678' \
 --header 'Content-Type: application/json' \
 --header 'Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.dadoFicticio.assinaturaFicticia' \
 --data '{ "urlRetorno": "https://cliente.exemplo.com/webhooks/apuracao-cbs" }'
 Exemplo de chamada (sem webhook)
 curl --location --request POST 'https://api.receitafederal.gov.br/apuracao-cbs/v2/pagamentos/{cnpj}' \
 --header "Authorization: Bearer $TOKEN" \
 --header 'Content-Type: application/json' \
 --data '{"urlRetorno":""}'
 4.5 Campos Retornados
 Campo 
 Formato 
 Descrição 
 tiqueteSolicitacao 
 String 
 Em caso de sucesso, tíquete gerado na requisição. 
 tEASegundos 
 Integer (segundos) 
 Em caso de sucesso, tempo estimado para atendimento da solicitação, em segundos. O valor -1 indica que não foi possível obter uma estimativa. 
 codigoErro 
 String 
 Em caso de erro - Identifica o erro ocorrido durante a requisição. Retornado apenas em caso de erro. 
 mensagemErro 
 String 
 Em caso de erro - Mensagem descritiva do erro ocorrido durante a requisição. Retornado apenas em caso de erro. 
 Exemplo de retorno em caso de sucesso (HTTP 201)
 {
 "tiqueteSolicitacao": "692b7b25-44cb-4415-8625-2b9522dd7933.B5E08D55",
 "tEASegundos": 120
}
 Exemplos de retorno em caso de erro
 Requisição inválida (HTTP 400): 
 {
 "codigoErro": "REQUISICAO_INVALIDA",
 "mensagemErro": "corpo da requisição inválido"
}
 Não autorizado (HTTP 401): 
 {
 "codigoErro": "NAO_AUTORIZADO",
 "mensagemErro": "consumidor não autorizado para este NI"
}
 Erro interno (HTTP 500): 
 {
 "codigoErro": "ERRO_INTERNO",
 "mensagemErro": "erro interno ao processar solicitação"
}
