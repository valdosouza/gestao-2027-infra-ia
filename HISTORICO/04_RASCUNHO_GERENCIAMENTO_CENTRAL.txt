# Contexto 
	Empresa Setes a desenvolvedora e mantenedora do sistema tambem será cliente do proprio sistema

# Objetivo
	Reorganizar a base setes_central para usar a tabela tb_institution ao inves de tenants criando os campos necessarios em tb_instituiton 
	Padronizar as outras tabelas para iniciar com tb_ na base setes_central
	Ajustar os bancos dados para dar suporte a criacao da Interface-UI de Supersuser para Iniciar os cadastros:
		1º Cadastrar clientes que devem estar com referencias nas duas bases: 
			1.1 setes_Central
					tenants - Levar estrutura para tb_institution e remover tenants
					tb_entity - Identifica o nome e apelido
					tb_company ou tb_person - Identifica a pessoa juridica ou fisica num cadastro unico geral 
					tb_address - Controlas mutiplos enderecos de cada entidade
					tb_institution  - Controla as licencas - e sera usado para indexar operacoes do cliente
					
			1.2 setes_+Schema
					tb_customer - Terao origem das tabelas tb_entity
					
			Um unico cadastro de cliente deve registrar uma entity que sera ao mesmo tempo Customer e institution e tenant			
			
		2º - Depois de cadastrar o cliente vamos cadastrar o usuario para permitir que o cliente faca o login
