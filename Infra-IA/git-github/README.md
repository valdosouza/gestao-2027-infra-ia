## 📋 Padrões Adotados

### Conventional Commits
```
feat(scope): description      # Nova feature
fix(scope): description       # Bug fix
docs: description            # Documentação
refactor(scope): description # Refatoração
test: description            # Testes
chore: description           # Manutenção
```

### Git Flow
```
main/               # Production-ready
├─ develop/        # Integration
├─ feature/nome/   # Feature branches
└─ hotfix/nome/    # Urgent fixes
```

### Semantic Versioning
```
v1.0.0  → Breaking changes (MAJOR)
v1.1.0  → New features (MINOR)
v1.0.1  → Bug fixes (PATCH)
```

## ⚠️ Importante

### GitHub Token (Não commit!)
1. Gerar em: GitHub → Settings → Developer Settings
2. Guardar em local seguro
3. NÃO colocar em .env commitado
4. Usar via `git config credential.helper store`

### Branches Protegidas
Recomendação para `main/`:
- Require pull request reviews
- Require status checks to pass
- Dismiss stale PR approvals
- Require branches to be up to date
