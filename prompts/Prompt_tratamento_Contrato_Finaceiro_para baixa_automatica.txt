# Contexto
	Criacao de Contrato financeiro para baixas automaticas
	
# Objetivo
	Controlar a baixa automatica de caixa somente se um caixa do usuario estiver aberta
	Controlar a baixa automatica de Banco somente se uma conta corrente estiver criada.
	
# Regra no faturamento
	Nao proibe faturamento e o financeiro deve ser gerado com baixa posterior
	
# Novo Metodo baseado no legado
	##Legado example
		reg_electronic_card.pas
			Funciona como um contrato.
				Existe vinculo com
					forma de pagamento
					Conta corrente
				Existem
# REgras
	Forma de pagamento sem contrato vai para o financeiro sem nenhum tipo de tratamento.
	
# Referencias legado
	un_cupom_fiscal.pas Linha 282 que desvia para linha 310 e usa Pc_LancaValorCartao

		Se havera algum tipo de agio ou prazo para recebimento
			Como o caso dos cartoes de credito
